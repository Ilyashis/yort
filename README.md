# Citia v2 — Уфа и 1-е Иткулово в 3D

Интерактивная 3D-копия двух мест Башкортостана в браузере: исторический центр Уфы (~4 км², 1056 зданий,
памятник Салавату Юлаеву, набережная Белой) и деревня 1-е Иткулово Баймакского района (483 постройки
среди леса и холмов, с участками, заборами и башкирскими домами). Место можно осмотреть сверху, пройти пешком и проехать на машине, в любое время суток.

Это вторая версия, написанная заново: новое ядро, новая картинка, новый интерфейс. Первая версия
осталась в ветке `main`; её доработки переносятся сюда по частям (см. ниже).

**Стек:** TypeScript · three.js · React 19 · Zustand · Vite. Данные — OpenStreetMap (ODbL), Copernicus DEM
и своя съёмка с дрона (рельеф и цвета домов Иткулова).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # модульные тесты
npm run build    # проверка типов и сборка
```

## Что есть

- **Два места** — переключатель слева вверху; выбор попадает в ссылку (`?place=itkulovo-1`).
- **Обзор** — карта двигается левой кнопкой, правая (или `Shift`) поворачивает и наклоняет, колесо — масштаб,
  двойной щелчок — подлететь, `W A S D` — лететь, `Q E` — поворот. Щелчок по дому — карточка: название, адрес,
  этажность, высота и откуда она взята, площадь, ссылка на объект OSM. Кнопка слева внизу — вид строго сверху.
- **Пешком** — встаёте на ближайшую улицу. `W A S D`, `Shift` — бег, щелчок по сцене захватывает мышь.
  Сквозь стены не пройти, под навесами — можно. Вверху — название улицы, справа — мини-карта по курсу.
- **За рулём** — аркадная физика: разгон и накат, руль мягче на скорости, в гору тяжелее, по траве медленнее,
  от стен отскок. `Пробел` — ручник, `Shift` — до 90 км/ч, `C` — вид из кабины, `R` — вернуть на дорогу.
  Ночью светят фары, при торможении — стоп-сигналы. Пять цветов кузова.
- **Время суток** — ползунок 0–24 ч, «Утро / День / Закат / Ночь» и «время идёт» (сутки за 6 минут). Солнце
  стоит как в середине июля на этой широте; в сумерках зажигаются окна, витрины и фонари.
- **Ссылка на вид:** `?time=21.5&mode=drive&view=x,z,дальность,поворот,наклон&help=0`.

## Как устроена картинка

- **Земля — один материал с масками.** Асфальт, плитка, грунт, газон, лес, вода, свет фонарей и затенение
  у стен рисуются на холстах (4096 и 2048 px) и читаются шейдером рельефа: никаких наложенных полигонов
  и мерцания, края покрытий сглажены, вблизи добавляется зерно асфальта, швы плитки и трава. Вода — тот же
  материал с бегущей рябью и отражением неба.
- **Рельеф** — Copernicus DEM (30 м), в Иткулове поверх него съёмка с дрона (шаг 1 м) с плавным переходом
  по краям снятого. Ближняя сетка — кусками по 96 клеток, дальше грубое кольцо до горизонта.
- **Здания** — одна сетка на всё место. Крыши: двускатные и односкатные на прямоугольных контурах, вальмовые
  на почти прямоугольных, «мансардные» (сдвиг контура внутрь) на сложных, плоские с парапетом. Части зданий
  (`building:part`) заменяют объём владельца. Фасады процедурные: штукатурка, кирпич, бревно, доска, панель;
  четыре раскладки окон (классическая, ленточная, панельная, деревенская с наличниками и ставнями), витрины
  с вывесками, стёкла отражают небо, ночью часть окон горит.
- **Небо** — свой купол: градиент по высоте, облака, диск солнца, луна и звёзды. Из того же неба берутся
  отражения окружения (PMREM), поэтому свет, дымка и небо всегда согласованы. Тень — одна карта 4096 px
  вокруг точки внимания с привязкой к текселям. Постобработка: MSAA, bloom, тональная кривая ACES.
- **Деревья** — семь процедурных моделей инстансами по плиткам 256 м с покачиванием на ветру: деревья OSM,
  парки, лес (упрощённые модели, ~46 тыс. в Иткулове), деревья у деревенских домов.
- **Мелочи** — фонари вдоль улиц со свечением, скамейки, осевая разметка и зебры, пьедестал и статуя
  Салавата Юлаева (`public/models/salavat-yulaev.glb`).

## Код

```
src/core      геометрия на плоскости, загрузка и разбор данных, пространственные индексы
src/engine    Engine (сборка сцены, рендер, режимы), terrain, buildings, sky, trees, props, controls
src/world     планировщики из v1: дома-модели, участки, палисадники (чистая логика с тестами)
src/three     слои из v1, которые рисуют эти планы; src/audio — звук из v1
src/state     хранилище интерфейса (Zustand)
src/ui        панели, мини-карта
scripts       выгрузка OSM и рельефа, обработка съёмки с дрона, лепка статуи (без изменений из v1)
```

Данные лежат в `public/data/territories/<id>/`; новое место — запись в `src/config/territories.json`
и `TERRITORY=<id> npm run data:fetch`.

## Перенесено из v1

- **Модели башкирских домов** — изба, пятистенок, дом с верандой, вальмовый, кирпичный, баня: дому OSM
  модель подбирается по размеру контура и по тому, какой стороной он стоит к улице; цвета кровли и стен —
  по съёмке с дрона. Вблизи — подробная модель, вдали — упрощённая.
- **Обустроенный посёлок** (переключатель в левой панели, включён по умолчанию) — участки вплотную, заборы
  (доска, профнастил, штакетник, горбыль, жерди), ворота с калитками, сараи, бани, теплицы, колодцы,
  поленницы, ульи, стога; огороды и подъезды к воротам рисуются на земле; в дворах — яблони и берёзы.
- **Палисадники** перед домами: штакетник, клумбы, кусты, деревца.
- **Звук** — музыка, звуки места, шаги по покрытию, мотор и удары машины; кнопка слева внизу.

Планировщики и слои этих доработок взяты из v1 без изменений (`src/world`, `src/three`, `src/audio`,
вместе с их тестами); к новому движку они подключены в `src/engine/village.ts`.

- **Редактор** (панель инструментов внизу, в обзоре): «Дом» `Y` — растяжкой или моделью из каталога щелчком,
  «Дорога» `T` (улица, переулок, просёлок, тропинка), «Забор» `B`, «Рельеф» `G` (поднять, опустить, выровнять,
  сгладить), «Выбор» `V` — двигать, растягивать и поворачивать дом за ручки, менять тип, этажность, крышу, цвета
  и модель, убирать дома, дороги и заборы дворов. `Ctrl+Z` / `Ctrl+Shift+Z`, сохранение правок в файл и загрузка.
  Правки хранятся в браузере в прежнем формате — правки, сделанные в v1, открываются и здесь (кроме убранных
  дорог OSM: у них в v2 другие ключи).
- **Подложка** — свой снимок сверху или ортофото GeoTIFF: совмещение по 2 и 4 точкам, перемещение, поворот,
  прозрачность, «спрятать дома и деревья».
- **Рельеф под жизнь деревни**: участок — плоскостью по своему уклону, под дорогами — ровное полотно, под
  домами и дворовыми постройками — площадки (тот же алгоритм, что в v1). Заборы участков — прямые.

Инструменты редактора, слой правок и подложка — код v1; со сценой v2 их связывает `src/engine/editing.ts`:
правки дорог перерисовывают маски земли, фонари и разметку, убранные дома прячутся из общей сетки зданий,
кисть рельефа меняет сетку высот, а здания, деревья, фонари и дворы встают на новую землю.

## Что осталось от v1

Конструктор здания по форме (BuilderPanel), выбор участка под застройку и мастерская моделей (`houses.html`).
Заборы не мешают пройти и проехать. Убранная в редакторе дорога OSM убирается вместе с фонарями и разметкой,
но тротуары-полигоны вдоль неё остаются.
